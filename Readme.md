# <center>Sorting Visualizer<center>

## Introduction
Sorting is a technique in which we arrange the elements in increasing or decreasing order according to the condition given.
There are many diffferent sorting algorithms. Some algorithms have higher time complexity and some has smaller. 
This project is to visualize the sorting technique. This will show how the sorting is working under the hood. It will help students in getting started with the sorting algorithms and make their journey on sorting easy.

## Method
We are going to create a blank canvas. The canvas will contain many bars. The bars will be of equal width and their height will be decided according to the number which it corresponds to.
